# Aurel Estates

A fictional luxury real estate agency website — an editorial one-page experience built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- Fonts (Cormorant Garamond and DM Sans) are self-hosted in `public/fonts`.
- Photography is loaded from Unsplash with responsive `srcset` sizes. All properties, prices, contact details and the agency itself are fictional demonstration content.
- No backend, enquiry form or third-party UI dependency is connected.
